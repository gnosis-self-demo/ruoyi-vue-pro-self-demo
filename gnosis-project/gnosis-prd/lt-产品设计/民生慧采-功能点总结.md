# 民生慧采 — 一站式采购平台 产品功能点总结

> 基于产品设计原型（0728kjsw）整理，共包含 34 个页面原型，覆盖采购全生命周期管理。

---

## 一、平台概述

**平台名称**：民生慧采 — 一站式采购平台

**定位**：面向中国民生银行内部采购业务的数字化管理平台，覆盖从采购需求提报、方案审批、电子评标、合同管理、供应商管理到付款结算的全链路业务流程。

**核心导航模块**：采购管理、合同管理、电子评标、慧采商城、供应商管理、我的数据

**首页四大智能板块**：
- **ai·采**：采购全流程节点导航（采购计划 → 需求受理 → 方案编制 → 方案审定 → 采购执行）
- **ai·购**：按业务维度分类（采购需求 / 合同管理 / 合同验收 / 合同付款）
- **ai·评**：审批待办入口（采购审批 / 集采委审议 / 采购评审）
- **ai·办**：多维度待办汇总（采购待办 / 合同待办 / 慧采待办 / 供应商待办）

## 二、功能模块详解

### 模块一：采购管理

#### 1.1 采购需求提报（procurement.html）
- **功能定位**：采购需求的列表管理页，全流程入口
- **查询条件**（9个）：需求单编号、名称、创建日期、状态、请购人、是否删除、管理范围、推荐供应商、中选供应商
- **操作功能**：发起采购申请、新增、批量删除、紧急采购
- **状态流转**：拟稿中 → 已审批
- **表格操作**：删除、受理、结果通知

#### 1.2 发起采购申请（purchase-apply.html）
- **功能定位**：多区块长表单，左侧锚点导航
- **五大区块**：
  1. **基本信息**：采购基本信息（25+ 字段，含标题/项目名称/预算金额/财审号/采购类型/采购方式/中选供应商数量/是否标准合同模板/建议评审方法/采购优先级/条线/是否涉及外包等）+ 厂商信息
  2. **采购项信息列表**：36列明细表格，支持添加/删除采购项，含采购项编码/名称/品类/需求书/资质模板/打分模板/金额/预算/厂商信息/代理商信息/费用类型等
  3. **网络安全审查**（待补充）
  4. **XC评估**（待补充）
  5. **附件信息**：支持打包下载、文件AI比对、上传/预览/下载/删除
- **底部操作**：保存草稿 / 发起采购申请

#### 1.3 小额分散采购（small-purchase.html）
- **功能定位**：小额采购批次管理列表
- **查询条件**（7个）：批次号、采购申请编号、采购项编号、状态、采购组织单位、商务谈判号、最后修改日期
- **状态流转**：创建批次 → 已提交交易中心 → 待中标签报审批 → 采购完成

#### 1.4 评标通知（bid-notice.html）
- **功能定位**：电子评标会议安排管理
- **查询条件**：项目名称、参评人员、参评日期
- **操作功能**：新增、导入、导出
- **表格字段**：项目名称、参评人员、参评日期、参评时间、参评地点

#### 1.5 批次管理（batch-management.html）
- **功能定位**：付款批次归集管理
- **查询条件**：批次号、送单人、付款流水号、归批时间范围
- **表格字段**：批次号、送单人、送单时间、归批时间、归批人、归批条数、归批金额、已付款条数、已付款金额、付款通道
- **业务流程**：送单人提交付款单 → 归批人归集批次 → 付款通道执行付款

### 模块二：合同管理

#### 2.1 合同起草（contract-draft.html）
- **功能定位**：从已完成的采购项中勾选发起合同起草
- **查询条件**（7个）：采购项编号、名称、采购方式、中选供应商、请购部门、项目名称、项目编号
- **表格**：25列采购项明细
- **初始化弹窗**：选择合同形式（项目合同/框架协议）、合同类型、是否使用标准模板
- **操作**：合同起草、列表导出、导出合同标的

#### 2.2 合同工作台（contract-workspace.html）
- **功能定位**：合同起草核心表单，左侧锚点导航 + 底部悬浮操作栏
- **六大区块**：
  1. **合同标的**：关联采购项表格 + 关联采购项金额录入
  2. **合同基本信息**：
     - 签报信息（16个只读反显字段）
     - 合同信息（19+ 字段：合同类型/名称/金额/履约日期/保质期/保修期/增值税率/二级分类/细分类别/工作量/合同概况等）
     - 维护的软件产品信息（表格 + IT资产同步/导出）
     - 主合同（协议）信息
     - 甲方联系人信息
     - 收款方信息（含跨境外包/外包类型/驻场标志）
  3. **付款计划**：快速模板选择（100/40-30-20-10/50-40-10/50-50/90-10/30-60-10）+ 动态付款表格（付款名称/金额/比例/日期/是否需验收/款项性质/发票期限）
  4. **采购需求**：采购申请关联表
  5. **XC评估**（待补充）
  6. **其他信息**：合同预览附件 + 文件AI比对 + 提交意见
- **提交流程**：前端校验 → 预览抽屉 → 确认提交 → 进入审批

#### 2.3 合同编辑（contract-edit.html）
- **功能定位**：修改已有合同草稿
- **核心字段**：合同子类、签署模型（标准/电子）、合同主体类型（双方/三方/多方）、业务场景、外包类型、模板选择
- **合同要素导入**：10个要素项（代理资质/备案地点/付款地点/付款节点/发票要求/有效期等）
- **附件管理**：按类型筛选 + 上传/下载/预览

#### 2.4 合同待办（contract-todo.html）
- **功能定位**：展示当前用户合同流程待办事项
- **表格字段**：标题（可点击）、发起部门、发起人、发起日期、流程处理步骤、到达日期、流程编号
- **安全特性**：页面水印保护（操作人姓名 + 日期）

#### 2.5 合同变更（contract-change.html）
- **功能定位**：合同变更申请管理
- **查询条件**：变更事项名称、编号、变更场景（内容变更/中止/提前终止/管理信息变更）、变更状态
- **表格**（16列）：变更事项名称/编号/场景/类型/原因/合同名称/编号/申请人/日期/生效日期/补充协议编号/当前节点/状态/影响评估/补充协议名称/操作
- **状态流转**：起草中 → 审批中 → 已完成 / 已驳回

#### 2.6 合同管理看板（dashboard-contract.html）
- **功能定位**：合同经办人个人工作看板
- **KPI指标**（5个）：经办总数、本月新增、履约中、即将到期、逾期
- **筛选维度**：时间范围、合同类型、履约状态、到期状态
- **四大模块**：
  1. 合同待办 & 预警中心（7个Tab + 4级预警分级）
  2. 合同全生命周期进度（6节点进度条 + 状态饼图 + 平均办结/归档时长）
  3. 合同风险自查面板（风险类型/等级/整改状态）
  4. 个人合同结构分析（类型金额柱状图 + 年度签约趋势折线图）
- **全量台账**：合同编号/名称/类型/金额/日期/状态/归档状态 + 导出台账/归档清单

#### 2.7 草稿列表（draft-list.html）
- **功能定位**：合同草稿管理与流转中心
- **查询条件**：合同名称、编号、状态、起草方式、供应商名称
- **操作功能**（5个）：发起法审、发起用印、合同报备、邮件发送供应商、列表导出
- **状态流转**：起草中 → 法审中 → 用印中 → 待生效 → 生效中 → 已过期

### 模块三：供应商管理

#### 3.1 供应商准入（supplier-access.html）
- **功能定位**：供应商准入申请管理
- **查询条件**：供应商编号、名称、创建时间
- **表格字段**：供应商编号/名称/简称、创建时间、节点名称（审批状态）、分行名称、查看流程
- **状态流转**：待审批 → 审批中 → 通过/驳回

#### 3.2 供应商看板（supplier-dashboard.html）
- **功能定位**：供应商全景数据看板（深色主题）
- **筛选维度**（6个）：供应商分类、合作状态、风险等级、内部评级、所属行业、年份
- **KPI指标**（6个）：总户数、年度新增、高风险数、黑名单数、A级占比、履约合格率
- **合作趋势**（6项）：本月新增/淘汰/续签/新增合同/活跃供应商/履约合格率
- **可视化图表**：行业分布环形图、企业性质饼图、合作年限柱状图、采购类型TOP5、风险等级分布、供应商TOP榜、风险预警榜单

#### 3.3 供应商风险评价（supplier-risk-evaluation.html）
- **功能定位**：风险评价批次管理
- **查询条件**：批次号、供应商名称
- **表格字段**：批次号、供应商名称、评价状态、高风险标记、关注类标记、风险评价总分、发起人、发起时间
- **评分体系**：0-5分制，好(绿)/差(红)

#### 3.4 供应商处罚（supplier-punishment.html）
- **功能定位**：批量录入供应商处罚信息
- **供应商选择**：弹窗搜索 + 批量选择
- **处罚信息字段**（13列）：供应商名称、统一社会信用代码、处罚原因、登记时间、认定日期、禁用机构范围、不良行为分类、禁用业务领域、处罚措施、附件、备注
- **处罚措施**：警告 / 暂停合作 / 列入黑名单
- **操作**：保存草稿 / 生效 / 提交

#### 3.5 供应商变更记录（supplier-change-record.html）
- **功能定位**：供应商信息变更历史管理
- **查询条件**：标题、供应商名称、变更时间、状态
- **表格字段**：标题、公司名称、变更时间、申请人、状态
- **变更类型**：名称变更、法定代表人变更、联系方式变更、经营范围变更
- **状态流转**：新增 → 待审核 → 已生效/已完成 / 已驳回

#### 3.6 供应商集中度详情（supplier-concentration-detail.html）
- **功能定位**：供应商采购金额集中度分析
- **筛选维度**：所属条线、领域、时间范围、供应商名称、付款通道
- **表格字段**：统计时间范围、供应商名称、占比、条线、领域、付款通道、合同金额、资源池付款金额
- **操作功能**：导出、手工生成、阈值配置

#### 3.7 供应商入库（supplier-inbound-detail.html）
- **功能定位**：将供应商加入正式供应商库
- **入库方式**：手动选择 / 文件导入（.xlsx/.xls）
- **表单字段**：标题、入库仓库、入库方式、审批流水号、入库依据（文件上传）、说明
- **操作**：取消 / 保存草稿 / 提交

#### 3.8 供应商出库（supplier-outbound.html）
- **功能定位**：供应商出库记录管理
- **查询条件**：供应商名称、出库日期
- **表格字段**：供应商名称、有无中选/参与项目、出库时间、出库事由、出库仓库、操作人
- **操作**：确认出库 / 恢复入库

### 模块四：数据看板

#### 4.1 领导看板（dashboard-leader.html）
- **功能定位**：管理层宏观管控数据大屏
- **筛选维度**：机构、部门、统计维度（年/季/月）、时间区间
- **KPI指标**（4个）：年度采购总金额、年度新增合同总金额、在办采购项目数、履约中合同总数
- **四大核心模块**：
  1. **体量结构分析**：物资/服务/工程类饼图、合同类型环形图、部门TOP10柱状图
  2. **全流程进度管控**：各节点平均耗时+超时率双轴图、状态分布环形图、超时流程TOP5
  3. **风险全景预警**：高/中/低风险统计、风险维度柱状图（超预算/无审批/逾期/未归档/付款异常/资料缺失）
  4. **年度趋势对比**：采购+合同金额柱状图、合规通过率+流程效率折线图（三年对比）
- **底部通栏**：合同履约状态堆叠柱状图 + 资金支付预测（未来3个月）

#### 4.2 全景视图（我的数据-全景视图功能介绍.md）
- **功能定位**：供应商全方位数字化视图
- **核心指标卡**：采购项总数/金额/总价项目/单价项目、合同总数/金额、订单总数/金额
- **多维分析**：
  - 效率指标：合同签署率、验收率、付款完成率、平均执行时长
  - 风险指标：履约异常率、合同变更率、中止率、提前解约率、到期未结清
- **分析维度**：供应商全景分布（TOP排行）、合同类型分析、合同状态分析、风险监控、时间趋势、对比分析（横向/纵向）
- **可视化图表**：环形饼图、横向柱状图、折线图、仪表盘、雷达图
- **数据联动**：钻取联动、筛选联动、跳转联动

### 模块五：任务中心

- **功能定位**：审批人待办工作台（三栏布局）

- **右侧详情面板**：锚点导航 + 基本信息/采购项关联/合同条款/付款计划/附件/审批历史

### 模块七：评价管理

#### 7.1 评价汇总（evaluation-summary.html）
- **功能定位**：供应商年度评价结果汇总
- **双维度切换**：条线（开发/运维/大数据/安全/测试/其他）× 采购类别（开发/咨询/工程建设/运维外包/运营维保/软硬件采购/测试/数据）
- **评价维度**（5项）：年度评价总分、项目制合同评价、资源池评价、信息科技外包管理执行团队评价、科技管理层评价
- **分数规则**：≥85绿 / ≥70普通 / <70红
- **操作功能**：导出、生成历史年度评价结果、导出历史年度评价结果

#### 7.2 资源池评价（resource-pool-evaluation.html）
- **功能定位**：供应商资源池响应指标评价
- **查询条件**（6个）：资源池类型、评价状态、供应商名称、批次号、项目经理
- **六项核心指标**：有效应答率、面试通过率、人员到岗率、人员稳定率、人员出勤率、优秀员工占比 → 汇总得分
- **资源池类型**：技术资源池 / 业务资源池 / 运维资源池
- **评价流程**：创建(未评价) → 发起评价 → 项目经理评价 → 上级审批 → 已通过/已退回
- **批量操作**：通过、退回、未评价邮件提醒、导出、删除

#### 7.3 科技负责人评价（tech-manager-evaluation.html）
- **功能定位**：科技管理层对供应商评价
- **多层级评价体系**：项目评价 → 资源池评价 → 商务管理团队评价 → 条线负责人评价 → 科技负责人评价 → 汇总总分
- **双维度切换**：与评价汇总页一致（条线 × 类别）
- **表格字段**：供应商名称、项目制合同金额/得分、资源池金额/得分、商务管理团队得分、条线负责人得分、科技负责人得分、当前总分

### 模块八：付款管理

#### 8.1 发票管理（invoice-management.html）
- **功能定位**：采购发票全生命周期管理
- **查询条件**：发票号码、发票类型（专票/普票/电子）、关联合同、发票状态
- **发票状态**（6种）：草稿 → 验证中 → 查验成功/查验失败/识别失败 → 已废弃
- **核心功能**：
  - 发票录入 + 影像文件上传（PDF/XML）
  - 发票查验（异步校验，自动同步开票日期/价税合计/购销方信息）
  - 发票分摊（分摊到合同采购项，实时金额校验）
  - 废弃 / 物理删除
  - 与报账系统数据同步
- **业务规则**：已被付款占用的发票不可废弃；查验成功后废弃需同步报账系统

#### 8.2 预付款核销（prepayment-writeoff.html）
- **功能定位**：预付款核销流程列表
- **查询条件**（7个）：核销代码、付款标题、付款状态、验收编号、供应商名称、发票快递单号、发票接收日期
- **表格**（15列）：核销代码、标题、预付款代码、当前处理人、供应商、状态、金额、时间、验收编号、发票信息、退回原因
- **状态流转**：待审批 → 审批中 → 已完成 / 已退回
- **操作功能**：批量发起OA流程

#### 8.3 人才池付款（talent-pool-payment.html）
- **功能定位**：人才池（人力外包/技术服务）合同付款管理
- **查询条件**（13个，最丰富）：付款流水号、标题、状态、金额、创建时间、付款时间、合同名称/编号、部门/条线、供应商、付款通道、资源池协议类型、审批单流水号、发票信息
- **表格**（18列，最多）：含工作量（人月）、合同类型/二级类型、资源池协议类型等
- **状态流转**：待付款 → 付款中 → 已付款 / 已退回
- **操作功能**：批量发起OA流程

#### 8.4 高频付款新增（high-frequency-payment-add.html）
- **功能定位**：新建高频账单付款申请
- **表单区块**：
  1. **基本信息**：标题、付款流水号、合同编号、验收编号、工作量、费用发生日期、价税合计、供应商、币种、部门/条线、上级审批人、内容摘要、审批意见
  2. **收款方信息**（自动带出，只读）：开户行、大额支付行号、收款方账号、收款人税号、税额、金额、报账系统编号
  3. **税务信息**（仅外币时显示）：企业所得税承担方、增值税承担方
  4. **关联发票**：勾选关联 + 金额录入 + 实时汇总校验
  5. **项目分割明细**（只读）：费用签报号、项目名称、采购项信息、金额
  6. **其他附件**：上传/打包下载
- **币种联动**：人民币隐藏税务信息，美元/欧元显示
- **发票校验**：付款总额不可超出发票剩余可付额度

## 三、全流程业务链路

```
采购需求提报 → 发起采购申请 → 采购方案审批 → 电子评标 → 确定中选供应商
                                                                    ↓
合同起草 ← 勾选采购项 ← 初始化合同（形式/类型/模板）
    ↓
合同工作台（6大区块填写）→ 保存草稿 / 提交申请
    ↓
草稿列表 → 发起法审 → 法审通过 → 发起用印 → 用印完成 → 合同生效
    ↓
合同履约 → 验收记录（首付/初验/终验/尾款）
    ↓
付款管理 → 发票管理（查验/分摊）→ 付款申请（高频/人才池/预付款核销）→ OA审批 → 付款完成
    ↓
供应商评价 → 资源池评价 → 项目制合同评价 → 商务团队评价 → 条线负责人评价 → 科技负责人评价 → 年度汇总
    ↓
数据看板 → 领导看板（全流程宏观监控）/ 合同看板（个人视图）/ 供应商看板（全景分析）
```

## 四、通用设计规范

### 4.1 页面布局
- 顶部固定导航栏（56px，蓝色渐变）+ 左侧菜单（180-200px可折叠）+ 右侧内容区
- 长表单采用左侧锚点导航 + 底部悬浮操作栏
- 列表页统一结构：查询面板 → 操作栏 → 数据表格 → 分页

### 4.2 配色体系
| 用途 | 颜色 | 色值 |
|------|------|------|
| 主色 | 蓝色 | #1e6fff / #0052d9 |
| 成功/完成 | 绿色 | #52c41a |
| 警告/待处理 | 橙色 | #fa8c16 / #faad14 |
| 危险/驳回 | 红色 | #ff4d4f |
| 正常/默认 | 灰色 | #e8e8e8 |

### 4.3 状态标签体系
- 蓝色：生效中 / 审批中 / 进行中
- 橙色：待审批 / 起草中 / 待处理
- 绿色：已完成 / 已通过 / 已付款
- 红色：已驳回 / 已退回 / 逾期 / 高风险
- 灰色：已废弃 / 正常

### 4.4 安全特性
- 页面水印保护（操作人姓名 + 日期）
- 操作权限按状态动态控制
- 发票查验与报账系统数据同步
