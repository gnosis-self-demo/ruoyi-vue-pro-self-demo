## 二、场景功能测试

### 2.1 场景1：字段直接匹配
- **测试用例数**: 5
- **通过**: 5 ✅
- **失败**: 0

**测试用例：**

| 编号 | 名称 | 输入 | 预期 | 结果 |
|------|------|------|------|------|
| 1.1 | 正常转换 | `{"contractNo": " ht2024001 ", "contractAmount": 1500000.567, "contractStatus": "生效", "priorityLevel": "高"}` | 转换成功，contractNo=HT2024001, amount=1500000.57, status=ACTIVE, priority=HIGH | ✅ PASS |
| 1.2 | 校验失败 | `{"contractNo": "ht-2024-001", "contractAmount": -100, "contractStatus": "审批中"}` | success=false，返回错误信息 | ✅ PASS |
| 1.3 | String转Integer成功 | `{"age": "25"}` | age=25（Integer类型） | ✅ PASS |
| 1.4 | String转Integer失败 | `{"age": "abc"}` | 降级为原值"abc"，记录错误 | ✅ PASS |
| 1.5 | 必填字段为空 | `{"name": "", "age": "", "email": ""}` | success=false，返回校验错误 | ✅ PASS |

**关键功能验证：**
- ✅ 智能类型转换：`'1'`→Integer成功，`'a'`→Integer失败但可降级
- ✅ trim转换：`" ht2024001 "` → `"ht2024001"`
- ✅ uppercase转换：`"ht2024001"` → `"HT2024001"`
- ✅ lookup映射：`"生效"` → `"ACTIVE"`
- ✅ round转换：`1500000.567` → `1500000.57`
- ✅ 校验规则执行：required、maxLength、pattern、min、enum
- ✅ 错误收集：errors和validationErrors分离
