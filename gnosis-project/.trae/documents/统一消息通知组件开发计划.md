# 统一消息通知组件开发计划

## 一、需求概述

开发一个统一消息通知组件 `gnosis-notice-center`，实现系统内消息的统一管理。

### 核心功能
1. **消息模板管理**：支持纯文本、富文本、附件等多种模板类型
2. **消息类型支持**：短信、邮件、站内信、微信通知
3. **消息发送能力**：集成真实的短信/邮件发送SDK，具备实际发送能力
4. **全链路管理**：消息创建、发送、状态跟踪、失败重试
5. **日志能力**：完整的消息发送日志记录

### 技术要求
- 严格遵循 `tech-ness.md` 技术栈要求
- 后端：Spring Boot 2.1.10 + MyBatis-Plus 3.5.4 + OpenGauss 3.0.0
- 前端：React 18 + Ant Design 5，端口 3006
- 数据库：使用 MyBatis XML 管理 SQL

## 六、关键实现细节

### 6.1 模板变量解析

模板内容支持变量占位符，格式：`${variableName}`

```java
// 模板内容示例
String template = "您的订单${orderNo}已创建，金额：${amount}元";

// 解析后
Map<String, Object> params = new HashMap<>();
params.put("orderNo", "ORD20240101001");
params.put("amount", "100.00");

String content = TemplateParser.parse(template, params);
// 输出：您的订单ORD20240101001已创建，金额：100.00元
```

### 6.2 消息发送流程

```
1. 接收发送请求
2. 查询模板信息
3. 解析模板变量
4. 根据通知类型选择发送器
5. 调用发送器发送
6. 记录发送日志
7. 更新发送状态
8. 失败时判断是否重试
```

### 6.3 消息发送器策略模式

```java
// MessageSender 接口
public interface MessageSender {
    String getNoticeType();
    NoticeSendResponse send(NoticeSendRequest request);
    List<NoticeSendResponse> batchSend(List<NoticeSendRequest> requests);
}

// 实现类
// SmsSender - 短信发送
// EmailSender - 邮件发送
// InboxSender - 站内信发送
// WechatSender - 微信发送
```

### 6.4 失败重试机制

- 最大重试次数：3次
- 重试间隔：指数退避（1s, 2s, 4s）
- 重试条件：网络异常、第三方服务不可用
