# 统一消息通知组件开发手册

## 一、模块概述

`gnosis-notice-center` 是统一消息通知管理模块，为系统提供消息模板管理、消息发送、发送日志记录、站内信管理等功能。

### 1.1 功能特性

- **消息模板管理**：支持纯文本、富文本、HTML 格式模板，可配置变量占位符
- **多通道发送**：短信、邮件、站内信、微信通知
- **全链路日志**：记录每次发送的详细状态、请求参数、第三方响应
- **发送重试**：支持失败消息自动/手动重试
- **API 调用**：提供 `NoticeApi` 类供其他模块直接调用

### 1.2 技术栈

| 组件 | 版本 | 说明 |
|------|------|------|
| Spring Boot | 2.1.10.RELEASE | 应用框架 |
| Spring Cloud | 2.1.4.RELEASE | 微服务框架 |
| MyBatis-Plus | 3.5.4 | ORM 框架 |
| OpenGauss | 3.0.0 | 数据库 |
| Hutool | 5.8.12 | 工具库 |
| FastJSON | 1.2.83 | JSON 处理 |

## 五、其他模块调用方式

### 5.1 引入依赖

在调用模块的 `pom.xml` 中添加：

```xml
<dependency>
    <groupId>com.gnosis</groupId>
    <artifactId>gnosis-notice-center</artifactId>
    <version>${project.version}</version>
</dependency>
```

### 5.2 使用 NoticeApi

```java
@Service
public class YourService {

    @Autowired
    private NoticeApi noticeApi;

    // 方式1：使用模板发送（推荐）
    public void sendByTemplate() {
        NoticeSendRequest request = new NoticeSendRequest();
        request.setTemplateCode("ORDER_CREATE");    // 模板编码
        request.setReceiver("13800138000");         // 接收人
        request.setParam("orderNo", "ORD20240101"); // 模板变量
        request.setParam("amount", "100.00");

        NoticeSendResponse response = noticeApi.send(NoticeChannelEnum.SMS, request, "userId001");
        if (response.getSuccess()) {
            System.out.println("发送成功，日志ID：" + response.getLogId());
        }
    }

    // 方式2：快速发送短信
    public void sendSmsQuick() {
        noticeApi.send(NoticeChannelEnum.SMS, "13800138000", null, "您的验证码是：123456");
    }

    // 方式3：快速发送邮件
    public void sendEmailQuick() {
        noticeApi.send(NoticeChannelEnum.EMAIL, "user@example.com", "订单通知", "<h1>您的订单已发货</h1>");
    }

    // 方式4：发送站内信
    public void sendInbox() {
        List<String> userIds = Arrays.asList("user001", "user002", "user003");
        noticeApi.sendInbox(userIds, "系统通知", "您有新的待办事项");
    }

    // 方式5：发送微信通知
    public void sendWechat() {
        noticeApi.send(NoticeChannelEnum.WECHAT, "openid_xxxxx", "您有新的消息");
    }
}
```

### 5.3 NoticeSendRequest 参数说明

| 字段 | 类型 | 说明 |
|------|------|------|
| templateCode | String | 模板编码 |
| noticeType | String | 通知类型（可选，优先级低于 channel 参数） |
| receiver | String | 接收人（手机号/邮箱/openid） |
| receivers | List\<String\> | 接收人列表（批量发送） |
| params | Map\<String, Object\> | 模板变量参数 |
| subject | String | 主题（快速发送时使用） |
| content | String | 内容（快速发送时使用） |
| attachmentPaths | List\<String\> | 附件路径列表 |
| async | Boolean | 是否异步发送 |

### 5.4 NoticeSendResponse 返回说明

| 字段 | 类型 | 说明 |
|------|------|------|
| success | Boolean | 是否成功 |
| logId | Long | 发送日志ID |
| requestId | String | 请求ID |
| errorMsg | String | 错误信息 |

## 六、模板变量使用

### 6.1 变量语法

模板内容中使用 `${variableName}` 格式定义变量：

```
您好，您的订单 ${orderNo} 已创建，金额：${amount} 元。
```

### 6.2 传递变量

```java
request.setParam("orderNo", "ORD20240101");
request.setParam("amount", "100.00");
```

### 6.3 模板类型

| 类型 | 说明 |
|------|------|
| TEXT | 纯文本 |
| HTML | HTML 富文本 |
| RICH | 富文本（含附件） |

```
│  调用 API   │
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  解析模板   │ ← 替换 ${variable} 占位符

       │
       ▼
┌─────────────┐

└──────┬──────┘
       │
       ▼
┌─────────────┐
│  选择发送器 │ ← 根据通道类型选择 SmsSender/EmailSender/InboxSender/WechatSender
└──────┬──────┘
       │
       ▼
┌─────────────┐
│  执行发送   │
└──────┬──────┘
       │
   ┌───┴───┐
   │       │
   ▼       ▼
 成功     失败
   │       │
   ▼       ▼
更新状态  更新状态+错误信息
   │       │
   └───┬───┘
       ▼
   返回结果
```

## 十、常见问题

### Q1: 如何新增消息通道？

1. 在 `NoticeChannelEnum` 中添加枚举值
2. 创建对应的 `XxxSender` 实现 `MessageSender` 接口
3. 在 `NoticeSendServiceImpl` 中注册新的发送器

### Q2: 模板发送失败如何排查？

1. 检查 `sys_notice_log` 表的 `error_msg` 字段
2. 查看 `third_party_response` 第三方响应
3. 检查模板变量是否完整

### Q3: 如何配置第三方服务？

在 `application.properties` 中配置对应的服务参数，然后在 `XxxSender` 中读取配置。

### Q4: 发送是同步还是异步？

默认同步发送。如需异步，设置 `request.setAsync(true)`，系统将返回初始日志记录，实际发送在后台执行。
