# 2026-07-15 工作日志

## gnosis-signature-plat 签章平台启动与验证

### 修复内容
1. **Jackson 版本冲突修复**: 父 pom.xml 的 dependencyManagement 中只覆盖了 `jackson-databind` 到 2.10.3，但 `jackson-core`/`jackson-annotations`/`jackson-datatype-jsr310` 仍是 Spring Boot 2.1.10 管理的 2.9.10 版本，导致 `NoClassDefFoundError: com/fasterxml/jackson/core/exc/InputCoercionException`。在父 pom 中补充了这3个依赖的版本管理，统一为 2.10.3。

### 启动方式
- **后端**: 由于 `spring-boot:run` 在多模块项目中会在父 pom 上执行失败，改用 `mvn dependency:build-classpath` 生成 classpath 文件，然后用 `java -cp "target/classes;$CP" com.gnosis.signature.SignaturePlatApplication` 直接启动
- **前端**: Vite 开发服务器 `vite --host`，端口 3008，代理 `/signature` → `http://localhost:8095`
