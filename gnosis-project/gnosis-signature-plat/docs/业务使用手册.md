# 签章平台模块 - 业务使用手册

## 1. 平台概述

### 1.1 平台定位
签章平台是一个"可插拔、可管控、可审计"的统一电子签章中台，为企业提供合法、安全、高效的电子签章服务。

### 1.2 核心价值
- **降低成本**：统一接入多供应商，降低采购和管理成本
- **提高效率**：标准化API，业务系统快速集成
- **安全合规**：符合《电子签名法》、GB/T 38540-2020等国家标准
- **风险可控**：完整审计日志，签章全程可追溯

## 2. 业务功能

### 2.1 文件管理
管理需要签章的文件，跟踪签章状态。

**签章状态说明：**
| 状态 | 值 | 说明 |
|------|-----|------|
| 未签章 | 0 | 文件已上传，等待签章 |
| 签章中 | 1 | 签章流程正在进行 |
| 已签章 | 2 | 签章完成，可下载 |
| 签章失败 | 3 | 签章过程出错 |

**操作流程：**
1. 上传文件 → 2. 选择模板 → 3. 选择流程 → 4. 发起签章 → 5. 下载已签章文件

### 2.2 模板管理
管理签章模板，定义签章位置和文件结构。

**模板类型：**
| 类型 | 说明 |
|------|------|
| CONTRACT | 合同模板 |
| AGREEMENT | 协议模板 |
| CERTIFICATE | 证明模板 |
| NOTICE | 通知模板 |
| OTHER | 其他模板 |

**签章位置：**
- 支持在模板中预设签章位置（坐标或关键字定位）
- 支持多签章位置配置

### 2.3 流程管理
配置签章流程，支持多种签署模式。

**流程类型：**
| 类型 | 说明 | 适用场景 |
|------|------|----------|
| SEQUENTIAL | 顺序签 | 按指定顺序依次签署 |
| COUNTER | 会签 | 多方同时签署 |
| PARALLEL | 并行签 | 多方并行签署，无顺序要求 |

**流程配置：**
- 支持多节点配置
- 支持会签、顺序签、并行签组合
- 支持签署人角色定义

### 2.4 印章管理
管理企业印章，控制印章使用权限。

**印章类型：**
| 类型 | 说明 |
|------|------|
| 公章 | 企业法定印章 |
| 合同章 | 合同专用印章 |
| 法人章 | 法定代表人印章 |
| 财务章 | 财务专用印章 |
| 发票章 | 发票专用印章 |
| 部门章 | 部门专用印章 |

**印章状态：**
| 状态 | 值 | 说明 |
|------|-----|------|
| 禁用 | 0 | 印章暂不可用 |
| 启用 | 1 | 印章正常使用 |
| 已销毁 | 2 | 印章已作废 |

**印章生命周期：**
创建 → 授权 → 使用 → 到期/销毁

### 2.5 供应商管理
管理签章服务供应商，实现多供应商统一管控。

**供应商类型：**
| 类型 | 说明 |
|------|------|
| ELECTRONIUM_SIGN | 电子签章服务 |
| CA_CERT | CA认证服务 |
| TIME_STAMP | 时间戳服务 |
| SEAL | 印章管理服务 |

**智能路由策略：**
- 成本优先：选择价格最低的供应商
- 负载均衡：根据当前负载分配请求
- 合规要求：根据业务合规要求选择

### 2.6 证书管理
管理数字证书，支持多CA互信互认。

**证书状态：**
| 状态 | 值 | 说明 |
|------|-----|------|
| 禁用 | 0 | 证书暂不可用 |
| 启用 | 1 | 证书正常使用 |
| 已过期 | 2 | 证书已过期 |

**证书管理要点：**
- 支持证书到期提醒（30天内）
- 支持多CA机构证书管理
- 支持国密SM2/SM3/SM4算法

### 2.7 审计日志
记录所有签章操作，保证全程可追溯。

**审计内容：**
- 操作类型（创建/修改/删除/签章等）
- 操作模块（文件/模板/流程/印章等）
- 操作人IP
- 操作结果（成功/失败）
- 请求参数和响应结果

## 3. 操作指南

### 3.1 发起签章（文件管理页面）

1. **进入文件管理页面**
   - 左侧菜单选择"文件管理"

2. **上传文件**
   - 点击"新建"按钮
   - 填写文件信息（文件名称、类型、描述等）
   - 选择关联的模板、流程、供应商
   - 点击"保存"

3. **发起签章**
   - 在文件列表中找到目标文件
   - 点击"签章"按钮
   - 确认签章信息
   - 等待签章完成

4. **下载已签章文件**
   - 签章状态变为"已签章"后
   - 点击"下载"按钮获取签章后的文件

### 3.2 配置签章模板（模板管理页面）

1. **创建模板**
   - 点击"新建"按钮
   - 填写模板编码、名称、类型
   - 上传模板文件或输入模板内容
   - 配置签章位置
   - 点击"保存"

2. **编辑模板**
   - 在模板列表中点击"编辑"
   - 修改模板信息
   - 点击"保存"

3. **启用/禁用模板**
   - 选中模板后点击"批量启用"或"批量禁用"

### 3.3 配置签章流程（流程管理页面）

1. **创建流程**
   - 点击"新建"按钮
   - 填写流程编码、名称
   - 选择流程类型（顺序签/会签/并行签）
   - 配置流程节点和签署顺序
   - 点击"保存"

2. **流程配置示例（JSON）**
```json
{
  "nodes": [
    {
      "role": "甲方",
      "order": 1,
      "required": true
    },
    {
      "role": "乙方",
      "order": 2,
      "required": true
    }
  ]
}
```

### 3.4 管理印章（印章管理页面）

1. **创建印章**
   - 点击"新建"按钮
   - 填写印章编码、名称、类型
   - 上传印章图片
   - 设置授权人和过期时间
   - 点击"保存"

2. **授权印章**
   - 选择印章，点击"编辑"
   - 设置授权人ID
   - 保存后印章状态变为"启用"

3. **销毁印章**
   - 选择印章，点击"批量禁用"
   - 印章状态变为"已销毁"

### 3.5 管理供应商（供应商管理页面）

1. **添加供应商**
   - 点击"新建"按钮
   - 填写供应商编码、名称、类型
   - 配置API地址和密钥
   - 填写联系人信息
   - 点击"保存"

2. **启用/禁用供应商**
   - 选中供应商后点击"批量启用"或"批量禁用"

### 3.6 查看审计日志（审计日志页面）

1. **查询日志**
   - 支持按操作类型、模块、结果、操作人筛选
   - 支持时间范围查询

2. **查看详情**
   - 点击"详情"查看完整的请求参数和响应结果

3. **导出日志**
   - 点击"导出"按钮导出日志数据

## 4. 业务集成

### 4.1 其他模块调用签章平台

在业务模块中注入 `SignatureApi` 即可调用签章服务：

```java
@Service
public class ContractService {

    @Autowired
    private SignatureApi signatureApi;

    /**
     * 合同签章流程
     */
    public void signContract(String contractFileId, String userId) {
        // 1. 选择模板
        SignatureTemplateQueryRequest templateQuery = new SignatureTemplateQueryRequest();
        templateQuery.setTemplateType("CONTRACT");
        
        // 2. 选择供应商（智能路由）
        SignatureSupplier supplier = signatureApi.selectSupplier("CONTRACT");
        
        // 3. 发起签章
        String result = signatureApi.signFile(
            contractFileId, 
            templateId, 
            processId, 
            userId
        );
        
        // 4. 查询签章状态
        Integer status = signatureApi.getSignStatus(contractFileId);
        
        // 5. 下载已签章文件
        if (status == 2) {
            String filePath = signatureApi.getSignedFilePath(contractFileId);
            // 处理签章后的文件
        }
    }
}
```

### 4.2 典型业务场景

#### 场景1：合同签署
1. 业务系统上传合同文件
2. 调用签章平台发起签章
3. 甲方先签署（顺序签）
4. 乙方后签署
5. 双方签署完成，下载合同

#### 场景2：多部门会签
1. 业务系统上传文件
2. 选择会签流程
3. 各部门同时签署
4. 全部签署完成，流程结束

#### 场景3：供应商智能选择
1. 业务系统发起签章请求
2. 签章平台根据策略选择最优供应商
3. 调用供应商API完成签章
4. 返回签章结果

## 5. 常见问题

### Q1: 签章失败如何处理？
1. 查看签章状态是否为"签章失败"
2. 检查审计日志中的错误信息
3. 确认供应商服务是否正常
4. 重新发起签章

### Q2: 如何更换签章供应商？
1. 在供应商管理中添加新供应商
2. 启用新供应商，禁用旧供应商
3. 后续签章请求将路由到新供应商

### Q3: 证书过期如何处理？
1. 在证书管理中查看即将过期的证书
2. 联系CA机构更新证书
3. 在系统中更新证书内容和过期时间

### Q4: 印章如何授权使用？
1. 在印章管理中创建印章
2. 设置授权人ID
3. 授权人即可在签章时使用该印章

## 6. 安全规范

### 6.1 数据安全
- 全链路采用SSL/TLS加密传输
- 敏感数据采用AES加密存储
- 支持国密SM2/SM3/SM4算法

### 6.2 权限控制
- 基于RBAC的权限管理
- 印章使用需严格授权
- 操作全程记录审计日志

### 6.3 合规要求
- 符合《电子签名法》要求
- 符合《数据安全法》要求
- 遵循GB/T 38540-2020国家标准
- 支持商用密码应用安全性评估（密评）
