# 签章平台模块 - 技术手册

## 1. 模块概述

### 1.1 模块定位
签章平台（gnosis-signature-plat）是一个统一电子签章中台，向下屏蔽不同供应商的技术差异，向上为业务系统提供标准、透明的签章服务。

### 1.2 核心特性
- **可插拔**：支持多供应商动态接入
- **可管控**：统一管控证书、印章、API密钥
- **可审计**：完整操作审计日志，支持区块链存证
- **国密支持**：全链路采用SM2/SM3/SM4国密算法

## 3. 数据库设计

### 3.1 表结构

| 表名 | 说明 | 核心字段 |
|------|------|----------|
| sig_file | 签章文件 | file_name, file_type, sign_status, template_id, process_id, supplier_id |
| sig_template | 签章模板 | template_code, template_name, template_type, sign_position |
| sig_process | 签章流程 | process_code, process_name, process_type, sign_order |
| sig_seal | 印章 | seal_code, seal_name, seal_type, authorize_user_id, expire_time |
| sig_supplier | 供应商 | supplier_code, supplier_name, api_url, api_key |
| sig_certificate | 证书 | cert_code, cert_name, ca_org, cert_sn, expire_time |
| sig_audit_log | 审计日志 | operation_type, operation_module, operation_result |

### 3.2 通用字段
所有表均包含以下审计字段：
- `create_user_id` varchar(128) - 创建人ID
- `update_user_id` varchar(128) - 更新人ID
- `create_time` timestamp - 创建时间
- `update_time` timestamp - 更新时间

### 4.2 Java API（供其他模块调用）

```java
// 注入API
@Autowired
private SignatureApi signatureApi;

// 1. 查询文件列表
SignatureFileQueryRequest query = new SignatureFileQueryRequest();
query.setFileName("合同");
PageResult<SignatureFileVO> result = signatureApi.queryFileList(query);

// 2. 签章操作
String signResult = signatureApi.signFile(fileId, templateId, processId, userId);

// 3. 查询签章状态
Integer status = signatureApi.getSignStatus(fileId);

// 4. 获取可用供应商
List<SignatureSupplier> suppliers = signatureApi.getAvailableSuppliers();

// 5. 智能路由选择供应商
SignatureSupplier supplier = signatureApi.selectSupplier("CONTRACT");
```

## 6. 启动说明

### 6.1 前置条件
1. Java 1.8+
2. Maven 3.6+
3. Node.js 16+
4. openGauss 3.0.0 数据库

### 6.2 启动步骤

```bash
# 一键启动（推荐）
cd command
start-signature-plat.bat

# 或分别启动
cd gnosis-signature-plat
start-backend.bat    # 启动后端
start-frontend.bat   # 启动前端
```

### 6.3 数据库初始化
首次启动时，系统会自动执行 `src/main/resources/db/signature/init.sql` 初始化表结构和基础数据。

## 8. 常见问题

### 8.1 端口占用
```bash
# 查看端口占用
netstat -ano | findstr :8095
# 结束进程
taskkill /PID <进程ID> /F
```

### 8.2 数据库连接失败
1. 检查数据库服务是否启动
2. 检查 application.yml 中的连接配置
3. 确认网络可达性

### 8.3 前端代理配置
前端通过 Vite 代理将 `/signature` 请求转发到后端 `http://localhost:8095`，配置在 `vite.config.js` 中。
